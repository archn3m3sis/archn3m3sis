## Currently building

### [`taildrives`](https://github.com/archn3m3sis/taildrives) — Go · Bubble Tea

A premium TUI + CLI for managing Tailscale Drive shares across a self-hosted mesh. Kitty graphics protocol image previews, fuzzy filesystem search with `Ctrl+D` directories-only filter, recursive directory stats with per-category file counts (`MARKDOWN FILES`, `IMAGES`, `CODE FILES`, …), multi-tier network topology visualization (ISP → router → device → containers), date-range-scoped report copy/print with OSC 52 clipboard support, and a polished step-progression wizard for adding/removing shares — `CATEGORY ›  DEVICE › PATH › NAME › CONFIRM`.

### [`n3m3sis-hermes-revolt-plugin`](https://github.com/archn3m3sis/n3m3sis-hermes-revolt-plugin) — Python

First-of-its-kind community adapter wiring the Hermes agent framework into Revolt (Bonfire) via WebSocket + REST. MIT-licensed `v0.1.0` contribution to the Hermes plugin ecosystem.

### [`nixos-config-srv-05`](https://github.com/archn3m3sis/nixos-config-srv-05) — Nix

Declarative NixOS configuration for a Dell PowerEdge R420 — boots fully-meshed with Tailscale + registered Taildrive shares + SSH mesh integration in a single `nixos-rebuild`. Replaced Windows Server 2025 on this hardware end-to-end via a USB minimal-ISO install path.

### [`n3m3sis-dev-portfolio`](https://github.com/archn3m3sis/n3m3sis-dev-portfolio) · [`n3m3sis-portfolio`](https://github.com/archn3m3sis/n3m3sis-portfolio) — TypeScript · Next.js

Personal portfolio + project showcase at [archn3m3sis.com](https://www.archn3m3sis.com) — the public face of Archn3m3sis Development.
